# macOS replacement migration Phase 3 evidence

- Phase: 3 — centralized manifests and generated contracts
- Completion date: 2026-07-16 (Australia/Sydney)
- Result: **PASS**

## Canonical inputs

- `manifests/archive-file-types.json` owns simple, compound, split-volume,
  document-role, UTType, and display-key policy.
- `manifests/shell-actions.json` owns request version, identifiers, order,
  valid selection shapes, multiplicity, Rust cases, and display keys.
- `manifests/native-inbound-events.schema.json` owns the bounded versioned
  envelope and typed OpenPaths, opaque ShellActionRequest token,
  HostedAuthCallback, and ReopenApplication payload schemas.

## Generated consumers

`scripts/generate-native-contracts.mjs` currently produces 19 deterministic outputs for:

- TypeScript archive policy, action/event types, policies, and localization keys;
- Rust archive manifest input and the shell-contract action enum/policies;
- Swift archive, action, and inbound-event contracts;
- macOS plist/UTType and native localization inputs;
- English and Simplified Chinese main-bundle Info.plist and Services resources;
- macOS packaging declarations and Windows NSIS extension declarations; and
- one cross-language conformance fixture.

The previous `src/app/archiveFileTypes.manifest.json`, hand-maintained Rust
`ShellActionKind`, hand-maintained TypeScript `QuickActionKind`, and old
single-purpose generator were deleted. Reference Swift archive/action policy was
not copied into the replacement; the generated Swift module is its only active
successor. The former repository remains immutable evidence until Phase 14.

`--check` compares every generated byte without rewriting and runs in
`npm run test:architecture` and `npm run build`.

action ordering, clean-source exact-one multiplicity, and identical action/event

## Exit decision

**PASS.** Archive types, shell actions, inbound event schemas, UTTypes,
localization keys, and package declarations have one canonical source with
cross-language fixture proof and drift protection.
